# SUMITASDOCS - Las Sumas de Víctor

Bienvenido al Vault de Documentación del proyecto educativo "Las Sumas de Víctor".

## Estructura del Proyecto

Este vault de Obsidian está diseñado para llevar el control del diseño, la arquitectura y las mecánicas del juego web orientado a enseñar matemáticas básicas mediante el uso de la motivación visual.

### Enlaces Rápidos
- [[Diseño_y_Mecanicas]] - Reglas del juego, sistema de progresión y recompensas.
- [[sesiones/mejoras_y_preparacion_despliegue]] - Mejoras pedagógicas, corrección de métricas de tutor, soporte PWA y despliegue.
- **Acceso Web en Vivo:** [https://rekels.github.io/sumitas/](https://rekels.github.io/sumitas/)

## Tecnologías Utilizadas
- **Frontend:** React + Vite
- **Estilos:** CSS puro (Vanilla) enfocado en animaciones e interfaces Mobile-First.
- **Almacenamiento:** Local Storage (Fase 1), Firebase (Fase 2).
- **Mascota Virtual:** Gráficos/Animaciones con temática de Dumbo.

## Objetivos del Proyecto
1. **Accesibilidad:** Interfaz fácil de usar, botones gigantes.
2. **Motivación:** Uso de animaciones de recompensas de forma constante.
3. **Progresión Adaptable:** Iniciar con sumas de 1 dígito y avanzar a 2 dígitos cuando esté listo.
4. **Monitoreo:** Panel de tutor para evaluar avances y estadísticas de forma asíncrona.
